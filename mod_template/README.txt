Sonic Unleashed 繁體中文化 MOD（Unleashed Recompiled 用）v1.6
作者：Yuuta Tsubasa
https://github.com/YuutaTsubasa/Unleashed-Recompiled-Traditional-Chinese-Mod
================================================================

【內容】
- 遊戲內文字：選單、村民對話、提示、道具說明、關卡與任務、媒體室、DLC 世界地圖文字
- 過場字幕：依日語配音的時間軸翻譯
- 介面圖片：標題選單、關卡／國家名稱、暫停選單、讀取畫面操作說明、名牌（索尼克／塔爾斯／奇普）等
- 字型：Noto Sans TC

【安裝】
方法一：Hedge Mod Manager（建議）
  1. 把整個 UnleashedTC 資料夾放進 Hedge Mod Manager 的 Unleashed Recompiled mods 資料夾
     （或把 zip 直接拖進 HMM 視窗安裝）
  2. 在 HMM 勾選「Sonic Unleashed 繁體中文化」，按「Save and Play」

方法二：不使用 HMM
  在遊戲資料夾（UnleashedRecomp.exe 所在處）建立 mods\ModsDB.ini 與 cpkredir.ini，
  格式同 Hedge Mod Manager 產生的檔案，指向 mods\UnleashedTC\mod.ini。

【使用】
  遊戲選項的語言設為「日文」（Japanese）即顯示繁體中文。
  語音語言可另外設為日語或英語。

【注意】
- Unleashed Recompiled 自己的設定選單、安裝器仍為原文（寫在 exe 內）。
- 對話名牌圖（索尼克／塔爾斯／奇普）同時以「整檔替換」與「附加封存檔（+Town_Common 等）」
  兩種方式提供，與其他替換 Town_Common / SystemCommonCore 的 MOD 並用時也能正常顯示。
- 移除：在 HMM 取消勾選即可，原始遊戲檔不會被修改。
